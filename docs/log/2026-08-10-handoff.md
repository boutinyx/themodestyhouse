```js
['trousers', /trouser|pant|jean|legging|culotte|wide.?leg/i],
['set',      /set|co.?ord|two.?piece|coordinate|\bensemble\b/i],
```

brands. Real titles are cached at `/tmp/feed-titles.json` (may not survive a reboot; re-probe

## 3. Concurrency — read this before you touch anything

**This working copy has at least one other live session, and it edits the same files.** During
this session it: swapped two About bands, removed the "Why this exists" eyebrow, dropped the
closing band, moved translation into `build-data.mjs`, and added a phone-menu scroll fade. A
nightly bot also pushed a catalogue refresh mid-work.

Three things this cost, all now rules:

1. **`git add <file>` stages the FILE, not your change to it.** Commit `b5e5705` says "cut the
   last four paragraphs" and is 68 insertions / 57 deletions, because it swept up another
   session's band swap. → **CLAUDE.md §10.30**: read `git diff --cached` and confirm every hunk
   is yours before committing.
2. **`git fetch` immediately before a long pipeline run, not just before the push.** The
   nightly refresh landed inside the window, and the whole build was against a stale base.
   Committing it would have reverted 78 delistings and 15,448 updates.
3. Ambiguous "go back to how it was" requests → ask which state. → **§10.29**.

`CLAUDE.md` is **gitignored**, so §10.29 and §10.30 exist only on this machine. They are not
in git and will not reach a fresh clone.
