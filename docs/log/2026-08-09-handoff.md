## Traps that cost real time here

1. **This working copy has concurrent sessions.** Three pushes landed from another session
   mid-work, and one rebuilt `.next` under a running `next start`, invalidating a whole audit
   pass (165 of 234 rows served 500s). Before committing: `git rev-parse --abbrev-ref HEAD`,
   stage by explicit path, and push with `git push origin HEAD:main`, then
   `git merge-base --is-ancestor HEAD origin/main` to prove it landed. CLAUDE.md §10.17.
2. **The shell's cwd persists between Bash calls.** A stray `cd .audit/visual` earlier made
   `npx next start` fail there and write a `next.config.compiled.js` into it.
3. **`components/VerifiedSpotlight.tsx` holds its CSS in a template literal.** A backtick
   anywhere in that block — including in a comment — breaks the build. It happened.
4. **Measure ink, not boxes, for optical alignment.** CLAUDE.md §10.27 and the note above the
   heart in `Header.tsx`.
