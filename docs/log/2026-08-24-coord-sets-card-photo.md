## What changed
- `public/category/coord-sets-2.png` — the new source (blush lace tunic + matching
  trousers, seated on a yacht). **New filename**, per CLAUDE.md §6: `public/` is served
  with `max-age=14400` and is not fingerprinted, so replacing bytes at the old path
  would be invisible to anyone who already loaded the page (§10.21).
  `public/category/coord-sets.png` is untouched on disk.
- `public/category/coord-sets-2-{400,700,1000}.webp` — generated by
  `node scripts/optimise-images.mjs` (required: `lib/staticImage.test.ts` fails if an
  original has no variants).
- `app/page.tsx` — `CATEGORY_SHOWCASE`'s `modest-sets` entry now points at
  `/category/coord-sets-2`, with a comment recording the swap.

No `zoom` / `origin` needed, unlike the Dresses / Abayas / Tops / Skirts swaps: the
source is 1069x1441 (≈3:4.04) against a 3:4 card, so `object-fit: cover` crops almost
nothing and the model already fills the frame.
